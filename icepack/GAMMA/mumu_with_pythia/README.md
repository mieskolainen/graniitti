# Gamma-Gamma to dimuons + single forward dissociation with GRANIITTI and Pythia

GRANIITTI generates $\gamma\gamma \to \mu^+\mu^-$ with one dissociated forward proton in LHE format.
Pythia 8 fragments the excitation as a string, showers and hadronizes the event, and writes HepMC3.

Use the common [icepack instructions](../../../tests/README.md) and [Pythia setup and comparisons](../../../tests/external/pythia/README.md).

The dataset selects string fragmentation for the forward excitation.
