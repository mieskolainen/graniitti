# Hard Pomeron Z production with GRANIITTI and Pythia

GRANIITTI generates single and double diffractive $Z \to \mu^+\mu^-$ events in LHE format. Pythia 8 showers and hadronizes the events and writes HepMC3. The same run generates the native Pythia Drell-Yan samples.

Use the common [icepack instructions](../../../tests/README.md) and [Pythia setup and comparisons](../../../tests/external/pythia/README.md).
